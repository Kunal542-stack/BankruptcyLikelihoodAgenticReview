# CardTransactionAgenticReview
For many companies, there are many times where they continue to operate ignoring financial issues until it is far too late, resulting in bankruptcy and negatively impacting the people working there. Determining bankruptcy is something that is very nuanced, and so when talking about it, figuring out what exactly is leading to bankruptcy and why is vital. This problem is what we aim to solve for this project. We will be aiming to create a pipeline where, for companies that have a high likelihood of bankruptcy, we can explain what is causing it and why. This pipeline will have two different phases, the ML layer and agentic layer, which will be discussed below.
We plan on using the SEC Financial statement for the most recent quarter, which would be the source of the various company variables, like total revenue and liabilities. We would also use 8-K reports and other data to determine which companies have declared bankruptcy. From there, we would use a classification model like XGBoost to determine if a company has a high likelihood for declaring bankruptcy or not. At that point, we would use two agents, an investigator agent and reviewer agent, to make a report explaining why the company has a high likelihood of declaring bankruptcy. This report would be the deliverable for the project.
